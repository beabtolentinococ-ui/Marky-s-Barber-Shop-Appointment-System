# Marky-s-Barber-Shop-Appointment-System

The Marky's Barber Shop Appointment System is a Python console-based application designed to make appointment scheduling easier, faster, and more organized. It allows customers to register, log in, book appointments, check their schedules, and cancel or update bookings. It also provides an admin interface where the owner or barber can manage customer accounts, view appointments, approve bookings, and monitor appointment records. This system aims to reduce long waiting times, prevent scheduling conflicts, and improve the overall appointment management process.

# Step-by-step process

1. Admin Login
Enter the admin username and password.
2. Admin Menu
Access the available management options.

3. Choose an Admin Action
- View Appointments
- Approve Appointment
- View Registered Accounts
- Create Appointment
- Cancel/Update Appointment
- Appointment Records

4. Manage Appointment Records
View, approve, create, update, or cancel appointments.

5. Log Out
Exit the admin menu and return to the main interface.

Explanation of each admin option
Option	What the admin does
1. View Appointments	Views all customer appointments.
2. Approve Appointment	Confirms pending appointments.
3. View Registered Accounts	Checks registered customer information.
4. Create Appointment	Books an appointment for a registered customer.
5. Cancel/Update Appointment	Cancels or changes an existing appointment.
6. Appointment Records	Views the complete appointment records, including status.
7. Log Out	Returns to the main interface.

Important admin workflow details
1. When a customer creates an appointment, its status is automatically Pending.
2. The admin checks the pending appointments.
3. The admin selects an appointment and confirms approval.
4. The appointment status changes to Approved.
5. If the admin creates an appointment for a customer, it is automatically approved.
6. If an appointment is updated, its status returns to Pending.
